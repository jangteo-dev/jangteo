# 장터 Jangteo — Brand Kit

The mark is a hanok gate under a GIWA roof (기와, *giwa*, means roof tile) with the red sun above it:
a market gate on GIWA.

## Folders

| Folder | What | Use it for |
|---|---|---|
| `logo/` | Mark (with and without its tile), horizontal lockup, stacked lockup — SVG + PNG | Website, docs, decks, partners |
| `social/` | `x-avatar-400`, `x-banner-1500x500`, `discord-icon-512`, `discord-banner-960x540` | X profile, Discord server icon and banner |
| `coin/` | Coin icon (milled rim and flat), 32 → 1024 px | Token lists, DEX listings, wallets, explorers |
| `favicon/` | `favicon.svg`, 32 px, Apple touch 180 px, 192 / 512 px | Website and PWA icons |
| `web/` | `og-image-1200x630` | Link previews on X, Telegram, Discord |

All text in the SVGs is converted to outlines, so they look the same on every machine.

## Type

- Wordmark and headings: **Hahmlet** (Google Fonts), bold.
- Body text: **Gowun Dodum** (Google Fonts).

## Rules

- Leave clear space around the mark of at least the sun's diameter.
- On light backgrounds use the mark on its dark tile, or `jangteo-mark-transparent-light`.
- On dark backgrounds use `jangteo-mark-transparent-dark`.
- Do not recolour the roof, rotate the mark, add shadows, or stretch it.
- The brand is Korean: write 장터 with Jangteo, never a translation.
