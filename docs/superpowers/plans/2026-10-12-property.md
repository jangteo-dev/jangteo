# Jangteo Property Implementation Plan

> Executed inline (executing-plans) by the same session that wrote the spec.

**Goal:** ship `docs/superpowers/specs/2026-10-12-property-design.md` on GIWA Sepolia.
**Architecture:** one registry contract `JangteoProperty` + one `PropertyShare` ERC-20 per property
(registry-controlled mint/burn, transfer hook settles rent). Web pages follow the 장외 (Jg*) pattern,
ops tasks follow `jangoe.ts`.
**Tech:** Solidity 0.8.28 / Foundry / OZ 5.1, Vite + React + viem, Node 24 ops.

## Tasks

1. **Contracts** — `contracts/src/property/PropertyShare.sol`, `contracts/src/property/JangteoProperty.sol`.
2. **Unit + fuzz tests** — `contracts/test/Property.t.sol`: create validation; buy limits / gate / window;
   finalize success (fee, reserve, issuer payout) and failure; refund; cancel by issuer + curator;
   transfers locked in Funding, gated receivers in Active; accrue over 0/1/n periods, arrears + fundReserve,
   eligible = 0 deferral; rent follows transfers; list / buyListing partial / cancelListing (incl. after Sold);
   sell with arrears > amount and < amount; redeem pro-rata; fees + sweep; rent claim after redeem.
   Run `forge test --match-contract Property -vv` → all pass.
3. **Invariant** — `contracts/test/PropertyInvariant.t.sol` handler over all actions with warps;
   invariant: registry tKRW ≥ Σ liabilities; escrowed shares == registry share balance.
4. **Deploy + seed** — `contracts/script/DeployProperty.s.sol` → `deployments/91342.property.json`;
   `scripts/publish-deployment.sh` merges `property`; seed 3 verified demo properties
   (`ops/scripts/seed-property.ts`); verify on Blockscout.
5. **Web lib + pages** — `web/src/lib/property.ts` (ABI, reads, actions), `web/src/pages/PropList.tsx`,
   `PropPage.tsx`, `PropNew.tsx`, routes in `app.tsx`, nav in `components/Chrome.tsx`, strings EN/KO,
   illustrations `web/public/property/*.svg`, hub card, FAQ/docs entry. `pnpm build` must pass (KO keys enforced).
6. **Ops** — `ops/src/property.ts` (`property:rent`), fee sweep, Telegram line, points part `property`,
   stats stall `property`. `pnpm typecheck && pnpm test`.
7. **Live e2e** — `ops/scripts/e2e-property.ts` with QA wallets on GIWA Sepolia: create (short window) → buy →
   finalize → list/buy → fund + accrue (period shortened only via a test property with 0 rent? no: use
   `fundReserve` + time) → sell → redeem; failed-sale → refund. UI e2e flow `property` in `ui-flows.ts`, mobile audit.
8. **Deploy web** — build, rsync with all excludes, QA crawl, commit, public sync.
